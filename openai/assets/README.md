# Assets for the ChatGPT and Claude listings

Two files are expected here before packaging:

- `icon.png` — square, 512×512, the Rqeim mark on a transparent or solid background.
- `logo.png` — the full lockup (mark + «رقيم» wordmark), width ≥ 512.

Brand color used in the manifest: `#0F766E` (must have at least 2:1 contrast against white and
against `#212121`; this one passes both).

Do not commit a screenshot instead of an icon: the directory crops to a square.
